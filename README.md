# Hệ thống Phát hiện Rò rỉ Khí Gas

Prototype web interface cho hệ thống giám sát và cảnh báo sự cố liên quan đến khí gas.

## 📂 Cấu trúc

```text
he-thong-phat-hien-ro-ri-khi-gas/
├── index.html
├── style.css
├── main.js
└── README.md
```

## 🎯 Mục tiêu

- Hiển thị trạng thái hệ thống
- Hiển thị cảnh báo và thông tin giám sát
- Làm nền tảng cho ứng dụng IoT và an toàn môi trường

## 🛠 Công nghệ

- HTML5
- CSS3
- JavaScript

## ▶️ Chạy

Mở `index.html` bằng trình duyệt hoặc dùng static web server.

> Chỉ cập nhật README; mã nguồn hiện có được giữ nguyên.
