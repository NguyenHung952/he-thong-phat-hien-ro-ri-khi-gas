# 📖 Giới thiệu

**Gas Leak Detection Dashboard** là một web dashboard mô phỏng hệ thống IoT giám sát và phát hiện rò rỉ khí gas theo thời gian thực.

Project mô phỏng:

- 🔥 Cảm biến khí gas MQ-2
- 📡 Vi điều khiển ESP32
- 📈 Hiển thị dữ liệu realtime
- 🚨 Cảnh báo khi vượt ngưỡng an toàn
- 📊 Dashboard trực quan bằng biểu đồ

Ứng dụng phù hợp cho:

- Học tập IoT
- Embedded Systems
- Smart Home Simulation
- Monitoring Dashboard
- Sensor Data Visualization
